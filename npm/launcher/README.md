# Codeidx

Native Rust MCP code indexing and terminal UI. `npm install -g codeidx` installs `codeidx-mcp` and `codeidx-tui` on supported platforms. The MCP command uses stdio; the TUI runs directly in your terminal. Linux x64 (glibc) and Windows x64 are supported by these npm packages; see [source and setup](https://github.com/Thatgfsj/codeidx) for details.
